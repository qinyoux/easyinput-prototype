### 关键判断（写进方案，等实测验证）

- **小智快更可能来自输出策略，不是 ESP32 算力**：持续连接 + 流式 ASR + 边生成边 TTS + 边收边播，
  优化的是 TTFA；easyop 任务台优化的是"完成判定正确性"。
- ⛔ 两种"快"不能混谈：TTFA 与"任务完整完成时间"必须分别验收。
- easyop 侧高概率瓶颈排序：①任务终态后才播报 ②`NullSink` 吞掉 LLM 增量 ③CLI Agent 启动/监控开销
  ④TTS 完整 PCM 缓存后才播 ⑤工具链更长 ⑥同槽排队。
- CLI 存在**确定性约 2 s 管道收尾尾延迟**（`process_exit` → drain 宽限），与模型无关，需单独打点。
- API Driver 与语音编辑页可能用**不同模型**（Driver 自带 endpoint/model/key），是常见误判点。
